## Our intended architecture

The OAuth flow was intentionally designed like this:

```
Browser
    │
    ▼
Deriv OAuth
    │
    ▼
DigitalOcean Backend
    │
    ├── Exchange authorization code + PKCE verifier
    ├── Obtain authenticated access token
    ├── Complete all required Deriv authentication
    ├── Fetch the authenticated account information
    ├── Create the authenticated session
    └── Return the completed authenticated session
    │
    ▼
Frontend
    │
    └── Restore the already-created session
```

The frontend should **not** be responsible for completing authentication after the exchange.

The backend should complete authentication before the frontend resumes.
