We are continuing work on the AI Bots execution engine in artifacts/ddbot-app.

Current status

The previous blocking issue has already been fixed.

The execution path now successfully reaches:

Strategy
→ Proposal
→ Proposal matched
→ BUY sent
→ Buy response received
→ contract_id received
→ proposal_open_contract subscribed

A real trade is successfully placed.

However, execution stops immediately afterwards.

The confirmed cause is that on the new Deriv endpoint, fields such as proposal_open_contract.profit are returned as strings, while the TradingEngine expects numbers.

Example:

poc.profit = "0.35"

The engine later performs:

this.profit += result.profit;
...
this.profit.toFixed(2)

which eventually throws:

TypeError:
this.profit.toFixed is not a function

This crashes executeBatch, stops the AI Bot sequence and closes the execution pipeline after only one trade.
