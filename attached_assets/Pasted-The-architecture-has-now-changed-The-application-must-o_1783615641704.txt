The architecture has now changed.

The application must operate in two completely separate modes:

==========================================
MODE 1 — PUBLIC MARKET MODE
==========================================

This mode starts automatically when the application loads.

It requires NO authentication.

It must initialize only:

✓ Global Tick Engine
✓ Public Market WebSocket
✓ Live Tick Feed
✓ Active Symbols
✓ SmartCharts
✓ DCircles
✓ AI Analysis
✓ Scanner
✓ Market History
✓ UI

Public Mode must NEVER:

- Restore sessions
- Read auth tokens to start login
- Perform OAuth
- Perform PKCE
- Fetch OTP
- Authorize WebSocket
- Request Balance
- Request Transactions
- Request Portfolio
- Start Refresh Cycle
- Start Trading

==========================================
MODE 2 — ACCOUNT MODE
==========================================

Account Mode must begin ONLY after the user explicitly clicks:

"Login"
or
"Connect to Deriv"

Only then may the application:

• Check for an existing session
• Restore a previous session (if still valid)
• Otherwise begin OAuth / PKCE
• Select account
• Fetch OTP
• Open authenticated WebSocket
• Authorize
• Load Balance
• Load Transactions
• Load Portfolio
• Enable Trading
• Start Refresh Cycle
